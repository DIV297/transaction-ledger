# API Documentation

Base URL: `http://localhost:3000/api`

All requests and responses are JSON (`Content-Type: application/json`). Amounts are numbers in major units with up to 2 decimals (e.g. `150.75`).

## Response format

**Success**
```json
{ "success": true, "data": { ... } }
```

**Error**
```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Request validation failed",
    "details": [{ "location": "body", "field": "amount", "message": "amount must be greater than 0" }]
  }
}
```

## Endpoints

| Method | Path | Description |
|---|---|---|
| POST | `/accounts` | Create an account |
| GET | `/accounts/:id` | Get account details |
| GET | `/accounts/:id/balance` | Get account balance |
| GET | `/accounts/:id/transactions` | Get transaction history (filter + pagination) |
| POST | `/transactions` | Add a credit or debit transaction |
| POST | `/transfers` | Transfer money between two accounts (bonus) |
| GET | `/health` | Health check (served at `/health`, no `/api` prefix) |

---

### 1. Create account

`POST /accounts`

Creates an account. The balance always starts at `0`. `id` and `created_at` are generated by the system.

**Request body**

| Field | Type | Required | Rules |
|---|---|---|---|
| `name` | string | yes | 1–100 characters, trimmed |

No other fields are allowed. Sending `balance`, `id` or `created_at` returns `400`.

```json
{ "name": "Alice" }
```

**Response `201`**
```json
{
  "success": true,
  "data": {
    "id": "6ae218c69716e12d8870f7f2",
    "name": "Alice",
    "balance": 0,
    "created_at": "2026-10-28T15:46:14.143Z",
    "updated_at": "2026-10-28T15:46:14.143Z"
  }
}
```

**Errors:** `400 VALIDATION_ERROR`

---

### 2. Get account

`GET /accounts/:id`

Returns the full account record.

**Response `200`**: same shape as the create response.

**Errors:** `400 VALIDATION_ERROR` (malformed id), `404 ACCOUNT_NOT_FOUND`

---

### 3. Get account balance

`GET /accounts/:id/balance`

**Response `200`**
```json
{ "success": true, "data": { "account_id": "6ae218c69716e12d8870f7f2", "balance": 100 } }
```

**Errors:** `400 VALIDATION_ERROR`, `404 ACCOUNT_NOT_FOUND`

---

### 4. Add transaction

`POST /transactions`

Adds a credit (balance goes up) or a debit (balance goes down) to an account. The balance update and the transaction insert happen in one atomic DB transaction.

**Request body**

| Field | Type | Required | Rules |
|---|---|---|---|
| `account_id` | string | yes | Must be an existing account |
| `type` | string | yes | `credit` or `debit` |
| `amount` | number | yes | > 0, at most 2 decimals, ≤ 1,000,000,000 |
| `reference_id` | string | yes | 1–100 chars, unique per account |
| `description` | string | no | ≤ 255 chars |

```json
{
  "account_id": "6ae218c69716e12d8870f7f2",
  "type": "debit",
  "amount": 30,
  "reference_id": "order-1001",
  "description": "Grocery payment"
}
```

**Response `201`**
```json
{
  "success": true,
  "data": {
    "id": "6ae218c79716e12d8870f800",
    "account_id": "6ae218c69716e12d8870f7f2",
    "type": "debit",
    "amount": 30,
    "description": "Grocery payment",
    "reference_id": "order-1001",
    "balance_after": 120,
    "transfer_id": null,
    "created_at": "2026-10-28T15:46:15.216Z"
  }
}
```

**Errors**
- `400 VALIDATION_ERROR`: invalid type, amount, reference_id or body
- `404 ACCOUNT_NOT_FOUND`
- `409 DUPLICATE_TRANSACTION`: the `reference_id` was already used for this account. Nothing is created and the balance does not change. `error.details.existing_transaction` contains the original transaction.
- `422 INSUFFICIENT_BALANCE`: the debit is larger than the current balance. The balance does not change.

---

### 5. Get transaction history

`GET /accounts/:id/transactions`

Returns the account's transactions, latest first (by `created_at`).

**Query params**

| Param | Type | Default | Rules |
|---|---|---|---|
| `type` | string | (both) | `credit` or `debit` |
| `page` | integer | `1` | ≥ 1 |
| `limit` | integer | `10` | 1–100 |

`GET /accounts/6ae218c69716e12d8870f7f2/transactions?type=debit&page=1&limit=2`

**Response `200`**
```json
{
  "success": true,
  "data": [
    { "id": "...", "type": "debit", "amount": 20, "reference_id": "r4", "balance_after": 100, "created_at": "..." },
    { "id": "...", "type": "debit", "amount": 30, "reference_id": "r3", "balance_after": 120, "created_at": "..." }
  ],
  "pagination": { "page": 1, "limit": 2, "total_records": 4, "total_pages": 2 }
}
```

A page past the last one returns an empty `data` array with valid `pagination`.

**Errors:** `400 VALIDATION_ERROR` (invalid id, type, page or limit), `404 ACCOUNT_NOT_FOUND`

---

### 6. Transfer money (bonus)

`POST /transfers`

Moves money from one account to another. It creates a `debit` on the source and a `credit` on the destination in a single DB transaction, so either both succeed or neither does. Both entries share the same `transfer_id` and `reference_id`.

**Request body**

| Field | Type | Required | Rules |
|---|---|---|---|
| `from_account_id` | string | yes | Existing account |
| `to_account_id` | string | yes | Existing account, different from source |
| `amount` | number | yes | Same rules as transactions |
| `reference_id` | string | yes | Must be unused on **both** accounts |
| `description` | string | no | Defaults to `Transfer to/from <account_id>` |

```json
{
  "from_account_id": "6ae218c69716e12d8870f7f2",
  "to_account_id": "6ae218c69716e12d8870f7f4",
  "amount": 30,
  "reference_id": "transfer-001"
}
```

**Response `201`**
```json
{
  "success": true,
  "data": {
    "transfer_id": "6ae218c99716e12d8870f819",
    "from_account_id": "6ae218c69716e12d8870f7f2",
    "to_account_id": "6ae218c69716e12d8870f7f4",
    "amount": 30,
    "reference_id": "transfer-001",
    "debit_transaction": { "...": "transaction object" },
    "credit_transaction": { "...": "transaction object" }
  }
}
```

**Errors:** `400 VALIDATION_ERROR`, `404 ACCOUNT_NOT_FOUND`, `409 DUPLICATE_TRANSACTION`, `422 INSUFFICIENT_BALANCE`

---

## Error codes

| HTTP | Code | When |
|---|---|---|
| 400 | `VALIDATION_ERROR` | Invalid body, params or query (unknown fields included) |
| 400 | `INVALID_JSON` | Malformed JSON body |
| 404 | `ACCOUNT_NOT_FOUND` | Account id does not exist |
| 404 | `ROUTE_NOT_FOUND` | Unknown endpoint or method |
| 409 | `DUPLICATE_TRANSACTION` | `reference_id` already used for the account |
| 413 | `PAYLOAD_TOO_LARGE` | Body larger than 100kb |
| 422 | `INSUFFICIENT_BALANCE` | Debit or transfer exceeds the balance |
| 500 | `INTERNAL_SERVER_ERROR` | Unexpected server error |
